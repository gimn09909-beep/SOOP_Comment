SOOP Station Comment Ranker - Standalone
==========================================

이 파일은 별도의 설치나 설정 없이 바로 실행 가능한 단독 실행 파일입니다.

[사용 방법]
1. 'soop-ranker.exe' 파일을 더블 클릭하여 실행합니다.
2. 서버가 시작되면 자동으로 웹 브라우저가 열립니다. (주소: http://localhost:5000)

[주의 사항]
- 프로그램 사용 중에는 검은색 콘솔 창을 닫지 마세요.
- 다른 곳으로 옮길 때는 이 'soop-ranker.exe' 파일 하나만 복사하면 됩니다.
